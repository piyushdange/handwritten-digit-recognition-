# 🧠 Handwritten Digit Recognition System

## 📌 Overview
This project presents a Handwritten Digit Recognition System developed using a Convolutional Neural Network (CNN). The model is designed to identify digits (0–9) from images based on a self-created dataset. The aim of this project is to understand the fundamentals of deep learning, image processing, and pattern recognition.

## 📂 Dataset
A custom dataset was created by writing digits on paper and capturing images using a mobile camera. Each image was labeled and organized into folders corresponding to digits 0–9. The dataset contains around 100 samples with multiple variations in handwriting style, size, and orientation to improve model learning.

## ⚙️ Technologies Used
- Python  
- TensorFlow / Keras  
- OpenCV  
- NumPy  
- Google Colab  

## 🔄 Preprocessing
The images were preprocessed before training:
- Converted to grayscale  
- Resized to 28×28 pixels  
- Normalized pixel values (0–1)  
- Applied thresholding to reduce noise  

These steps ensure consistency and improve model performance.

## 🤖 Model
A CNN model was built using convolutional layers for feature extraction and dense layers for classification. The model was trained on the custom dataset and optimized using appropriate loss functions and optimizers.

## 📊 Results
The model achieved good accuracy on the dataset and is able to predict handwritten digits effectively. Some misclassification may occur due to limited dataset size and similarity between certain digits.

## 🚀 Features
- Custom handwritten dataset  
- Image preprocessing pipeline  
- CNN-based digit classification  
- Real-time prediction using web interface
